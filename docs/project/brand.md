# Brand

The **RustFlare** mark is a hexagon of three concentric outlines with a four-pointed flare at its centre. Mark files: `docs/img/logo-mark-dark.svg` (for dark backgrounds), `docs/img/logo-mark-light.svg` (for light backgrounds), and `web/public/logo-mark.svg` / `favicon.svg` (the web UI).

| | Dark background | Light background |
|---|---|---|
| Background | `#0E0C0B` | `#FFFFFF` |
| Mark | `#F2652A` | `#D4501A` |
| Wordmark "Rust" | `#FFFFFF` | `#1A1412` |
| Wordmark "Flare" | `#F2652A` | `#C2410C` |

Wordmark: **Space Grotesk Bold**, tight tracking (-0.03em), written "RustFlare" (capital F) in prose. Code, crates and commands stay lowercase (`rustflare-server`, `/opt/rustflare`).

The UI uses the same orange as its accent colour. The red bullseye and crosshair over the live view are a separate, functional choice (they must stand out against an orange-tinted H-alpha image).
